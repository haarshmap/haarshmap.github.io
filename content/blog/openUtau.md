A while ago, after constant reminders from my friend about how his birthday was coming up, I thought maybe I should try something as a small surprise to him. But what could that surprise be? and so after some thoughts and an aimless stare at the empty screen later I found myself installing OpenUtau on a whim at 1 AM.
<br>
<br>
Now this blog is for the people who want a quick guide on installation the software and the voicebank of their choice. This does not delve into any sort of advanced topics and so it's really upto you to figure that part out so good luck with it.
<br>
<br>
Anyways, the installation part is quite simple, go to the official <a href="https://www.openutau.com/" class="button-link-accent" target="_blank">OpenUtau website</a>, and install OpenUtau bassed on your operating system.
<img src="/openutaublog/openUtauDownload.png" alt="OpenUtau homepage">

Now, after installation open the application and you will be greeted with this screen, 
<img src="/openutaublog/openutauhomepage.png" alt="OpenUtau homepage">

Now, click on the new project and you will be finding this screen,  
<img src="/openutaublog/OpenUtauProj.png" alt="OpenUtau homepage">

Now, before we make our first song, we first need to install our singer and if it isn't obvious by the site, we shall be using kasane teto for this one. To get her voicebank, visit the official page of <a href="https://kasaneteto.jp/utau/" class="button-link-accent" target="_blank">Kasane Teto</a> and install either the japanese library set <span class="text-muted">(the first one)</span> or the english library set <span class="text-muted">(the tenth one)</span>. In this tutorial we installed the japanese library set.


After the installation, go back to the openUtau project that we opened and at the left side of the screen, we can see the list of tracks. Now, go to track 1 and hover at the select singer option, you should be able to find the option to choose the singer.
<img src="/openutaublog/SelectSingerOption.png" alt="OpenUtau homepage">
Well there you have it, we have successfully installed OpenUtau and Kasane Teto. Hopefully you got the installation part done without any hiccups and are able to use it properly.
